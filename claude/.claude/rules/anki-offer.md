When a turn involved genuinely teaching or explaining a concept — the user asked "how does X work / what is X / explain X", or worked through understanding something (a mechanism, a piece of code, a distinction, a mental model) — offer at the end to capture it as an Anki flashcard.

Keep the offer to one line, e.g. "Want an Anki card for this?". Only offer when there's a durable, factual takeaway worth spaced repetition — skip it for opinions, planning/strategy discussions, one-off command output, or trivial lookups. Don't offer twice for the same concept in a session.

If the user says yes, use the `anki-card` skill for the format and workflow.
